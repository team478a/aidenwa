# Stage 4A Readiness Operations

Stage 4A is mock-only. It does not authorize or enable real calling.

1. An organization administrator enters approval facts and submits them.
2. A system administrator reviews the facts and records an approval or rejection reason.
3. An authorized administrator sets conservative call, duration and budget limits.
4. An organization administrator registers only consent-confirmed limited-test destinations.
5. A system administrator permits the logical provider name while production remains disabled.
6. Operators review `/production-readiness`. Written approval and real provider remain incomplete/unavailable.
7. API and Worker recheck safety immediately before dispatch. A failed condition records reason codes.

Telephone destinations are shown and audited only in masked form. Provider credentials must not be stored; only a future secret-manager reference key is permitted.

Threshold usage is based on deterministic mock cost in Stage 4A. It is not a quotation or actual provider charge.
